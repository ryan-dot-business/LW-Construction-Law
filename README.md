# LW Construction Law

Static landing-page prototype. No build step or dependencies required.

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000.

## Hosting

Serve the repository root as a static site; `index.html` is the entry point.

The contact form is a demonstration and does not send inquiries. Connect a submission endpoint before accepting real inquiries.

The hero image is loaded from Unsplash. Team portraits originate from the firm's public website; the supplied LW SVG is included.
