# LW Construction Law

Static landing-page prototype for LW Construction Law.

## Preview locally

Run `python3 -m http.server 8000` from the repository root, then open http://localhost:8000.

## Hosting

Serve this directory as a static site. No build step or dependencies are required. The entry point is `index.html`.

The contact form is a demonstration: it does not send or store inquiries. Connect a reviewed submission endpoint before using it for real inquiries.

The hero uses an external Unsplash image. Team portraits originate from the firm's public website; the supplied LW SVG is included. Confirm final image permissions and copy before public launch.
